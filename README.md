# contenido-viral

Skill de Claude Code para escribir guiones de contenido corto que **retienen y además venden** —
reels, TikToks y shorts — y para validar la idea antes de gastar producción en ella.

No es un generador de ideas: **diagnostica la idea primero** con el test de convergencia y solo
después escribe. Si la idea no pasa el filtro, lo dice y propone reformulaciones en vez de
redactar mejor algo que no va a funcionar.

## Qué hace

- **Filtra la idea** con el Umbral Mínimo de Viralidad (test 40-60) antes de escribir una línea.
- **Genera 5 ganchos alternativos** por guion, de tipos distintos, con recomendación razonada.
- **Escribe el guion por bloques** con marcas de curiosity point, loop, pausa y notas de edición.
- **Audita guiones existentes**: dónde se cae la retención y qué técnica falta en ese segundo.
- **Arma lotes y calendarios** sin que todas las piezas suenen a la misma plantilla.

## Los siete modos

| Modo | Para qué |
|---|---|
| A — Concepto | Reel de 45-60s sobre una analogía o anécdota. El más frecuente |
| B — Historia | Cuando hay material real. Estructura narrativa con caída obligatoria |
| C — Lista | Alcance alto, profundidad baja. Máximo 1 de cada 4 piezas |
| D — Anuncio | Contenido pagado. Hook → Meat → CTA demostrativo |
| E — Intro educativa | Las 3 P's: Proof, Promise, Plan |
| F — VSL | 5 P's o 5 W's según qué tan conocida sea la industria |
| G — Venta orgánica | Atención → Problema → Solución → Prueba social → Acción |

## Las tres leyes que la diferencian

1. **El 80% del resultado es la idea, no el guion.** No existe redacción que salve una mala idea.
2. **La zona de convergencia.** Ni demasiado nicho (techo de ~3.000 visitas) ni demasiado general
   (viraliza y no vende). El test es medible: de cada 100 personas, 40-60 deben reaccionar bien.
3. **El QUÉ, no el CÓMO.** La moraleja entrega el principio, nunca el paso a paso completo.
   Regalar el cómo entero produce virales que no dejan seguidores ni clientes.

## Instalación

```bash
git clone https://github.com/Pedro265h/contenido-viral.git ~/.claude/skills/contenido-viral
```

Se activa sola al pedir un guion, ganchos o una auditoría de contenido corto. También directo con
`/contenido-viral`.

## Fuentes del método

Aplica frameworks y principios públicos de **Víctor Heras** (zona de convergencia, mecánica de
guion, retención), **Ramiro** (catálogo de ganchos, la ley del qué), el patrón de 4 pilares del
**Canal de Lima**, el framework **Hook-Retain-Reward** con las 3 P's y los frameworks de VSL, y el
análisis de un corpus de 34 reels de referentes LATAM y BR. Método aplicado, no texto reproducido.
